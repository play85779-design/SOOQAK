# V58 — أساس تقييم البائع بعد التعامل، دون تقييمات وهمية
تاريخ: 2026-11-21
حالة التنفيذ: جزئي / تأسيس آمن، وليس تفعيل تقييمات حقيقية.

## المنفذ
إضافة قسم واضح في ملف البائع يفيد أن التقييمات غير مفعلة حتى تتحقق المنصة من إتمام التعامل ومن أهلية من يقيم. لا نجوم وهمية، ولا متوسطات تقديرية، ولا نماذج تسمح بإرسال تقييم بلا تحقق. اختبارات واجهة مخصصة.

## شروط تفعيل V58 كاملة لاحقًا
- سجل تعامل مكتمل مرتبط بمشترٍ وبائع حقيقيين، وليس بمجرد النقر على زر «تم البيع».
- سياسة تفويض على الخادم: مشتري الصفقة فقط يقيم البائع، تقييم واحد لكل صفقة، ولا يسمح البائع بتقييم نفسه.
- حق الإبلاغ والاعتراض، وعدم كشف البريد أو الجوال أو بيانات المحادثة في التقييم العام.
- سياسة احتفاظ ومكافحة إساءة وتدقيق على قاعدة تجارب قبل أي ترحيل للإنتاج.
- اختبار متكامل لقيود RLS وعمليات التلاعب، ثم موافقة صاحب المشروع قبل تطبيق قاعدة البيانات الحية.

لا تغيير لقاعدة البيانات، لا نشر للإنتاج، لا تكاليف.
