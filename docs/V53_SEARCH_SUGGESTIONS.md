# V53 — اقتراحات البحث وتصحيح الأخطاء البسيطة
التاريخ: 2026-11-21
الفرع: develop/v53-search-assist

## ما تغير
- قائمة اقتراحات تحت مربع البحث، متجاوبة مع لوحة المفاتيح والتفاعل باللمس.
- اقتراح تكملة الكلمات في عناوين الإعلانات والأقسام والمدن، وتصحيح الخطأ الكتابي البسيط (تبديل أو نقص أو زيادة حرف / تبديل ترتيب حرفين متجاورين) عند اختيار المستخدم فقط.
- تطبيع الهمزات والتشكيل والألف المقصورة والتاء المربوطة لدعم البحث العربي.
- لا يصحح ما يكتبه المستخدم تلقائياً، بل ينتظر أن يضغط على اقتراح واضح.
- يعرض اقتراحات قائمة على الإعلانات العامة السارية فقط + الأقسام والمدن؛ لا يمس سجلات الإعلانات المخفية أو المباعة أو رسائل خاصة.
- DOM آمن باستخدام textContent، دون حقن مدخلات المستخدم في HTML.
- لا طلبات شبكة إضافية من كود الاقتراحات، ولا يحتفظ باستعلامات مستخدم في التخزين؛ وظيفة البحث الأساسية القديمة لا تزال تعمل بصورة مستقلة.
- لم تتغير قاعدة البيانات أو موقع الإنتاج أو خدمة البريد.

## كيفية الاختبار
tests/v53-search-assist.spec.cjs
- تصحيح "سيارر" إلى "سيارة" واختيار نتيجة الإعلان.
- اقتراح إكمال "سيار" مع ArrowDown/Enter وإغلاق Escape.
- عدم اقتراح أسماء الإعلانات المخفية أو المباعة؛ عدم تنفيذ HTML من استعلامات المستخدم.
الاختبارات على بيانات محاكاة ومتصفح Chromium المحلي؛ لا يشمل تأكيدًا على مستخدمين حقيقيين.
