## قواعد التنفيذ والقبول
- اعمل من أحدث فرع صحيح بعد قراءة سجل التطوير والجدول الرئيسي وقائمة الـ200. أرقام الإصدارات الجديدة تُخصص بعد فحص التعارضات.
- مراحل: A رموز التصميم والخلفية والهيدر؛ B البحث والفلاتر؛ C البانرات والأقسام والمتاجر؛ D التنقل والمقاسات؛ E مراجعة بصرية واختبار انحدار.
- كل مكون HTML/CSS وتفاعلات حقيقية؛ أصول الصور منفصلة وخفيفة ومصرح بها. لا تحويل صورة البوستر إلى صفحة ثابتة. احتفظ بالشعار والبانرات القديمة حتى اعتماد البدائل.
- لا عدادات أو عروض أو توصيل أو توثيق وهمي. لا تغييرات إنتاج أو قاعدة بيانات أو تكلفة أو دمج دون موافقة.
- اختبر البحث والفلاتر ومسحها والمنطقة والمدينة والتنقل والمصادقة والرسائل والتنبيهات والمفضلة والمتاجر وإضافة إعلان والسلايدر؛ لوحة مفاتيح وتباين وأسماء وصول وتقليل حركة.
- لكل بند: لقطة قبل وبعد، حالة، نتيجة اختبار، رابط PR/SHA/معاينة. لا يغلق بند فاشل ولا يكرر في الجدول؛ المؤجل يحتاج سببًا.
- 10/10 هدف فني وليس نتيجة اختبار. قرار القبول بعد معاينة فعلية ومراجعة المالك.
- هذه المقارنة مبنية على اللقطات لا فحص حي كامل. البوستر البصري لا يثبت وجود الخدمات.
