# V54 — البحث حسب المدينة والحي
التاريخ: 2026-11-21
الفرع: develop/v54-city-district

## الهدف
تطوير الفلتر الحالي دون تغيير نظام الإعلانات:
- زيادة خيارات المدن السعودية مع الحفاظ على القائمة القديمة.
- البقاء على اختيار المدينة دون تحديد موقع GPS أو عنوان المستخدم.
- الإبقاء على حقل الحي نصيًا حرًا ومتاحًا للبحث.
- توفير اقتراحات أحياء موجودة في الإعلانات العامة السارية في المدينة المختارة، إن توافرت بيانات أحياء.
- عند تغيير المدينة، يُمسح اسم الحي السابق لتجنب البحث غير المنطقي بين مدينتين.
- عزل السجلات المخفية والمباعة والمنتهية عن الاقتراحات؛ لا ينشأ API أو جدول بيانات جديد.

## الاختبار
tests/v54-city-district.spec.cjs
1. المدن السعودية الإضافية وقابلية البحث باسم الحي في بيانات تجربة.
2. تغيير المدينة يمسح الحي السابق؛ اقتراح الأحياء لا يعرض إعلانات مخفية أو مباعة.
يعتمد النجاح على فحص GitHub مع بقية اختبارات الإصدارات السابقة.

## حدود التنفيذ
الفلترة في السحابة تدعم شروط المدينة والحي من نظامها السابق، ولم تتغير هنا قاعدة البيانات أو إدارة الحسابات أو صلاحياتها. البيانات التجريبية ليست دليلًا على نتائج حقيقية لجميع المدن، وتوفر الاقتراحات يعتمد على إدخال الحي في الإعلان.
لا نشر للإنتاج، ولا خدمات مدفوعة.
