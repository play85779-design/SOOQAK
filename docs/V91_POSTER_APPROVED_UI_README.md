## القواعد المعتمدة
- العربية RTL؛ الأسعار والأرقام بالصيغة الإنجليزية 0-9، دون تحويل اللغة إلى الإنجليزية.
- أخضر `#006638` وبرتقالي `#ff8917` وأبيض وخلفيات فاتحة وأيقونات مشرقة.
- خط Readex Pro للعناوين، وخط Tajawal للنصوص. تحميل مجاني عبر Google Fonts مع بدائل محلية.
- رسم حقيبة التسوق وشعار SVG ورسم متجر ملون، بطاقة إعلانات بصور حقيقية فقط إن توفرت.
- تصميم يختلف بذكاء بين 330 و390 و790 و1180 بكسل؛ لا قص، لا تمرير أفقي، ولا لافتة طويلة تدفع الإعلانات لأسفل.
- لا أرقام مبيعات أو شهادات توثيق أو تقييمات أو طلبات غير موجودة في قاعدة البيانات.
- لا إجبار على شاشة ترحيب إذا كانت تعيق التصفح، والحساب الموحد للأفراد والتجار محفوظ.

1. مرور Playwright مع اختبارات الوظائف الحالية وتحقق RLS وصلاحيات الحسابات.
