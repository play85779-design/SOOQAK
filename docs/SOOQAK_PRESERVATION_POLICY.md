# سياسة الحفظ والاستمرارية — سوقك SOOQAK
اعتماد المالك: 24 نوفمبر 2026، جلسة 13.
- حفظ كل دفعة تطوير أو إصلاح أو اختبار في GitHub على فرع مراجعة مع Commit SHA وPR ورابط نتيجة الاختبار. لا يُعد الحفظ دمجًا أو نشرًا.
- حفظ التصاميم الأصلية والنسخ المعتمدة والقرارات ومحاضر التسليم في Google Drive، وربطها بفهرس التنفيذ وقائمة 200 في Google Sheets.
- التحقق بإعادة قراءة الملفات والروابط وحالة الاختبارات؛ تمييز المحاكاة من التشغيل الحقيقي، وعدم إغلاق البنود دون دليل.
- قبل الانتقال إلى جلسة جديدة: محضر آخر حالة، الفرع وSHA وPR، الروابط، الاختبارات، المتبقي والعوائق. بدء التسليم مبكرًا؛ لا توجد نسبة موثوقة لسعة المحادثة.
- لا حذف أو دمج أو تغيير إنتاج أو قاعدة بيانات أو صرف دون موافقة المالك. لا حفظ مفاتيح أو أسرار أو بيانات شخصية في مستودع عام أو مستندات غير محمية.
- الحفظ لا يغني عن اختبار استعادة نسخة احتياطية مستقلة؛ لا تدّع أن النسخ الاحتياطية الحية متاحة قبل التحقق.
