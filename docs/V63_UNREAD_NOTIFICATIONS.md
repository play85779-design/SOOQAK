# V63 — تنبيهات الرسائل الجديدة (حماية الترتيب)
تاريخ: 21 نوفمبر 2026
الفرع: develop/v63-unread-notification-race-safety

## المنجز
- البنية السابقة تعرض عدد الرسائل غير المقروءة وتدعم تنبيه متصفح اختياري عندما يكون سوقك مفتوحًا.
- إضافة معرّف متزايد لطلبات عدد الرسائل: ردّ الشبكة القديم لا يلغي عددًا أحدث أو يطلق تنبيهًا مكررًا.
- إبطال أي طلب تعداد معلّق عند تغيير الحساب أو تسجيل الخروج.
- الاحتفاظ بشرط عدم إعلان الزيادة في أول قراءة baseline.
- عدم طلب صلاحيات إشعار المتصفح تلقائيًا؛ الإذن فقط عند ضغط المستخدم في إعدادات التنبيهات.

## حدود
تنبيهات الويب الحالية ليست Push خلفية أثناء إغلاق الموقع أو SMS، ولا يوجد ادعاء خلاف ذلك. قواعد الخادم وإشعارات حسابين فعليين تبقى غير مختبرة.
لا نشر للإنتاج، لا SQL ولا خدمات مدفوعة.
