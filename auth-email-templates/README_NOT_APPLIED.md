# قوالب بريد سوقك | SOOQAK — لم تُطبق بعد

الموضع: Supabase Dashboard > Authentication > Email Templates.

1. `confirm_signup.html`: قالب Confirm signup — عنوان الرسالة: `تأكيد بريدك الإلكتروني | سوقك | SOOQAK`.
2. `magic_link.html`: قالب Magic Link — عنوان الرسالة: `رابط تسجيل الدخول | سوقك | SOOQAK`.

هذه ملفات جاهزة للمراجعة والنسخ إلى لوحة Supabase. لم تُحدّث إعدادات Supabase خلال V36.
المتغير `{{ .ConfirmationURL }}` يجب أن يبقى كما هو حتى يعمل رابط الدخول؛ لا ترسل محتويات بريد أو رموز حقيقية للاختبار.
تغيير اسم/عنوان **المرسل** نفسه يتطلب إعداد SMTP أو خدمة إرسال موثقة وقد يتطلب نطاقًا، ولم يُنفذ.
